01 · What's custom

Built on xiaozhi-esp32, tuned for the Goouuu V2

A fork of the XiaoZhi AI voice assistant firmware, customized for the Goouuu ESP32-S3 V2 dual-display board.

F·01

Dual-display layout

TFT carries the full-area chat; the OLED keeps the face. Each screen does what it does best.

TFT + OLED
F·02

Status top bar

WiFi, time, and battery percentage pinned to the top of the TFT — glanceable, always visible.

LVGL
F·03

ADC battery monitor

Real battery percentage from the ADC, with a low-battery popup when it's time to charge.

adc_battery_monitor
F·04

Power saving

Idle states that draw less — the display rests when you're not talking to it.

power manager
F·05

Animated idle backgrounds

Starfield, particles, and wave GIF backgrounds on the TFT while idle, via LvGif playback.

LvGif
F·06

Volume on GPIO 38/39

Dedicated volume buttons wired to the board's real pins — no more menu diving.

GPIO 38/39

03 · Build & flash

ESP-IDF, one board target

Standard ESP-IDF workflow — set the target, pick the board, build, flash.

terminal — esp-idf ≥ 5.4
$ idf.py set-target esp32s3
$ idf.py menuconfig
  Xiaozhi Assistant → Board Type → bread-compact-wifi-lcd
$ idf.py build flash
